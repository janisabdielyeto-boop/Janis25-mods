Portfolio of native C++23 mods developed with **Geode SDK v6.0.0** for Geometry Dash (`2.2091`) by **Janis25**.

## Projects
1. **`hidden-secrets-in-main-levels/`** — Interactive hidden sequences, custom modal UI (`FLAlertLayer`), and deterministic frame-by-frame timeline & reverse audio engine (`Dry Out` / `Secret Out`).
2. **`new-gamemodes-animations/`** — Procedural physics-driven sprite kinematics (`PlayerObject` hooks) for custom gamemode animations.
