# New Gamemodes Animations (`janis25.new_gamemodes_animations`)

Built for **Geode SDK v6.0.0** (Geometry Dash `2.2091`, C++23).

## Implemented Mechanics
- **Dynamic Kinematics (`PlayerObject::update`)**:
  - Velocity-driven squash-and-stretch deformation for Cube, Robot, and Spider modes.
  - Angular banking and pitch response for Ship, UFO, and Wave modes.
  - High-speed spin scaling for Ball and Swing modes.
